📖 OOP Architecture & Python Implementation

This system is engineered following strict Object-Oriented Principles, Clean Architecture, and Python standards.

1. Abstraction & Inheritance

Person (ABC) defines abstract methods implemented polymorphically by Customer and Supplier.

2. Encapsulation

Protected attributes (_person_id, _name, _mobile_number) guarded with Python properties & setters.

3. Custom Domain Exceptions

MedicineNotFoundError, OutOfStockError, ExpiredMedicineError, InvalidPrescriptionError.

4. Decorators & Generators

@log_action decorator records timestamped telemetry; sales_report_generator() yields records with generator memory efficiency.
